# Simranjeet Kaur Portfolio

A responsive static portfolio website prepared for GitHub Pages.

## Upload to GitHub Pages

1. Rename the repository to `simran2001-dev.github.io` if that is the GitHub username.
2. Open the extracted website folder.
3. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets` folder to the repository root.
4. Commit the files to the `main` branch.
5. In GitHub, open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose **main** and **/(root)**, then click **Save**.
8. The site should become available at `https://simran2001-dev.github.io/` after GitHub finishes deployment.

Do not upload only the ZIP file. Extract it first and upload its contents.
